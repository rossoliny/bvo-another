# Русские тексты карты

Это дополнения к `w3x-content/`. Сборка `--lang ru` подставляет отдельные поля в памяти и упаковывает результат с исходными путями и именами. Исходники не изменяются. Отсутствующие переводы остаются на исходном языке. Пока переводов нет, RU-карта использует все исходные тексты; сборка сообщает число подставленных полей.

Разрешены только следующие файлы в `units/`:

- `campaignabilitystrings.txt`
- `campaignunitstrings.txt`
- `campaignupgradestrings.txt`
- `commonabilitystrings.txt`
- `itemabilitystrings.txt`
- `itemstrings.txt`

Создавай файлы по мере перевода. В каждом указывай существующие секции объектов и только переведённые поля:

```ini
[I000]
Name=Сердце Баунта
Tip=Купить Сердце Баунта
```

Разрешены `Name`, `Tip`, `Ubertip`, `Researchtip`, `Researchubertip`, `Description`, `Bufftip`, `Buffubertip`, `Propernames`, `Revivetip`, `Awakentip`, `Untip`, `Unubertip`. Каждое поле должно существовать в соответствующей секции исходного файла. Кодировка — UTF-8; комментарии на отдельных строках начинаются с `//`.

Сохраняй количество значений/уровней, кавычки вокруг значений с запятыми, ссылки вида `<A000,DataA1>`, `%d` и другие форматные подстановки в каждом уровне, а также разметку Warcraft III (`|n`, `|c...|r`). Для переводимых способностей в конце расширенного описания изучения и обычного расширенного описания каждого уровня должна быть ровно одна строка `Updated by Rossoliny.` согласно AGENTS.md.

Не копируй сюда полные профили: `Art`, `Order`, `Hotkey`, требования, ассортимент и другие нетекстовые поля запрещены даже с исходными значениями. JASS, WTS, SLK, бинарные объекты и прочие файлы пока не поддерживаются. Этот README не попадает в карту. Переводы готовятся отдельно; сборка их не создаёт и не обновляет.
